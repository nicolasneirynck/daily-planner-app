# Roadmap

Daily Planner is under active development. The roadmap outlines the main areas of planned functionality and potential future improvements.

Features are grouped by development focus rather than fixed release dates. Priorities and scope may evolve as the project progresses.

## Implemented

The current version of Daily Planner provides the foundation for organizing daily activities:

- **Daily planning:** Organize activities into six predefined time blocks.
- **Activity management:** Create, edit, reschedule, and delete planned activities.
- **Activity tracking:** Mark activities as important or completed.
- **User authentication:** Basic account registration and sign-in.

For a complete overview of the current functionality, see the [README](../README.md#features).

## Planned Features

The following features are planned for future development. They are grouped by functionality and are not listed in a fixed implementation order.

### Reusable Activities & Routines

- Create, edit, and manage reusable activities.
- Add saved activities to the daily planner.
- Schedule activities to repeat on selected days and time blocks.

### Step-by-Step Guides

- Break activities down into manageable steps.
- Create, edit, and reorder steps.
- Attach step-by-step guides to reusable activities.
- Track progress by marking individual steps as completed.

### Checklists

- Create and manage reusable checklists.
- Add, edit, and remove checklist items.
- Track completion and reuse checklists with their items reset.
- Attach checklists to planned activities.

### Reminders & Alarms

- Configure reminders to review the daily plan.
- Set alarms for scheduled activities.
- Manage, snooze, and dismiss alarms.

### Planning Improvements

- Customize the number, names, and order of personal time blocks.
- Assign estimated durations to activities.
- Receive warnings when activities exceed the available time in a time block.
- Reschedule activities using drag-and-drop.
- Improve activity forms and date selection.

### Activity Time Tracking

- Measure and record the time spent on activities.
- Review previously recorded durations.

### Account Management

- Reset forgotten passwords.
- View and update account information.
- Delete a user account.

## Potential Future Features

The following ideas may be explored as the application evolves.

- **Buddy support:** Allow users to invite a trusted person to help structure activities, break them down into manageable steps, and contribute to step-by-step guides.

These ideas are not yet part of the committed development scope.
